# 卡片与项目数据

## project.json

| 字段 | 默认 | 说明 |
|---|---|---|
| `name` | — | 项目名，也是成片文件名 |
| `course` / `chapter` | — | 页眉、页脚显示的课程与章节 |
| `fps` / `width` / `height` | 24 / 1280 / 720 | 16:9，不建议改 |
| `tts_model` | `qwen-audio-3.1-tts-flash` | 千问语音合成模型；换模型要选对应音色 |
| `voice` | `longanhuan_v3.1` | 千问音色 ID（女声）。男声可用 `xunanchuan_v3.1` |
| `rate` | `1.12` | 语速倍数 0.5–2.0，实测约 5.0 cps；想到 5.5 用 `1.2`。也接受 `"+12%"` 写法 |
| `tts_format` / `tts_sample_rate` | `mp3` / `24000` | 音频格式与采样率，一般不用改 |
| `lead` | 0.4 | 首卡前的空白秒数 |
| `tail` | 0.9 | 每卡旁白结束后的留白 |
| `gap` | 0.55 | 相邻元素最小起始间隔（24fps 下 13 帧） |
| `pause_duration` | 3.0 | 暂停卡时长 |
| `pause_text` | 请暂停，自己先算一遍 | 暂停卡底部提示条的主文案 |
| `module_gap` | 0.5 | 换模块时额外留白（秒） |
| `end_pad` | 0.4 | 片尾留白 |
| `first_title_at` | 0.35 | 首卡标题起始秒数，避免开场空页 |
| `modules` | — | `{"A": {"label","accent","tint"}}`，决定左侧色条与标签 |

## cards.json

顶层可以是数组，也可以是 `{"cards": [...]}`。

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一，同时是配音文件名 `audio/<id>.<格式>` |
| `module` |  | 对应 `modules` 的键；缺省取第一个 |
| `layout` |  | `concept` / `list` / `steps` / `chips` / `stem`，默认 `concept` |
| `title` | ✅ | 卡片标题，自动成为第一个 `title` 节拍 |
| `ref` |  | 材料页码，如 `[1-1 p21–p23]` |
| `screen` |  | `main` 节拍内容为 null 时使用 |
| `tts` | ✅ | 旁白原文；触发词必须在此字符串中 |
| `diagram` |  | 图示名，见 `diagrams.md` |
| `diagramParams` |  | 图示参数 |
| `diagram2` |  | 触发词：图示数值层延后到这句话再出现 |
| `beats` | ✅ | `[kind, content, trigger]` 的数组 |
| `pause_after` |  | `true` 则本卡后插 3 秒暂停卡（保留本卡画面 + 遮罩 + 提示条） |

### 节拍类型

| kind | 用途 | 呈现 |
|---|---|---|
| `title` | 卡片标题 | 顶部逐字写出（缺省自动插在最前） |
| `main` | 一句话主张 | 46px 衬线；含 LaTeX 时走公式遮罩 |
| `note` | 要点 | 25px，带方块项目符 |
| `problem` | **题面行** | 25px，浅色整块卡片；相邻 `problem` 自动拼成一张卡（首尾圆角） |
| `step` | 解题步骤 | 自动编号 ①②③，25px |
| `banner` | 结论条 | 左边框 + 淡色底 |
| `formula` | 独立公式 | 32px，居中留白 |
| `chip` | 标签/选项 | 先虚线灰框，讲到时点亮（适合“五种分布”这类并列项） |
| `diagram` | 图示 | 右侧 410×392 区域，左→右擦除出现 |

### 题面卡（layout: stem）

例题题干卡要把**课本原题完整放上屏**，而不是只列条件。写法：

```json
["problem", "某设备有效期 \\(X\\) 的分布函数为", "某设备"],
["problem", "\\(F_X(x)=\\begin{cases}0, & x<0\\\\[2pt] 1-e^{-x/5}, & x\\ge 0\\end{cases}\\)", "x 小于零取 0"],
["problem", "求：(1) 均值 \\(E(X)\\)　(2) 方差 \\(D(X)\\)", "求两件事"]
```

- 连续 `problem` 会拼成一块浅色卡片，中间不留缝；组内多余空间全部落到卡片底部，不拆散。
- 题号写在 `title` 里（如 `例题 1.12｜指数分布：均值与方差`），屏幕上一眼能对回教材。
- 分段函数用 `\\begin{cases}` 内联写，不要用 `$$`；`display` 公式在卡里会撑破行高。
- 题面之后可留 1–2 条 `note` 当“解题钥匙”，但不许出现答案。

### 触发词写法

- 必须是 `tts` 中**连续出现**的片段（允许跨词，但不能跨标点被改写）。
- 越短越容易命中，但不要短到在句首重复出现（`t_at` 取第一次出现）。
- 想“开场就出”，用 `__start__`；`title` 缺省会用它，固定在 0.15s。
- 找不到时 `build_timeline.py` 会报 `missing` 并退出，按提示换词。

### 屏幕文字

- 一张卡最多一句主张 + 3–5 条要点；屏幕文字 ≤20 字（公式不计）。
- 公式一律 `\(...\)` 或 `$$...$$`，不要用 Unicode 上下标、不要贴图。
- 题干卡只放已知与所求；解法提示留给旁白或解析卡。

### 旁白

- 口语化，像聊天：先给结论，再解释，最后点一个易错点。
- 一张卡 150–300 字，约 30–55 秒；例题解析可到 60 秒。
- 讲到某个元素时再出现那个词——触发词就是“镜头切换点”。
- 例题：题干卡旁白只读题 + 提醒“先自己算”，解析卡逐步拆解并点坑。

## 一个最小示例

```json
{
  "id": "A1", "module": "A", "layout": "concept", "ref": "[1-1 p21]",
  "title": "随机变量不是“随机的数”，是映射",
  "screen": "\\(X:S\\to\\mathbb{R}\\) 单值映射",
  "tts": "先纠正一个直觉：随机变量不是一个飘来飘去的数，它是一个函数。",
  "diagram": "map",
  "beats": [
    ["title", null, "随机变量不是一个"],
    ["main", null, "它是一个函数"],
    ["note", "每个结果 \\(e\\) 贴一个实数标签", "贴了个标签"]
  ]
}
```
