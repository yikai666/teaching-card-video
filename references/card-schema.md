# 卡片与项目数据

## project.json

| 字段 | 默认 | 说明 |
|---|---|---|
| `name` | — | 项目名，也是成片文件名 |
| `course` / `chapter` | — | 页眉、页脚显示的课程与章节 |
| `fps` / `width` / `height` | 24 / 1280 / 720 | 16:9，不建议改 |
| `voice` | `zh-CN-XiaoxiaoNeural` | edge-tts 音色 |
| `rate` | `+12%` | 让中文落在 5.5 cps 左右；用一次试听校准 |
| `lead` | 0.4 | 首卡前的空白秒数 |
| `tail` | 0.9 | 每卡旁白结束后的留白 |
| `gap` | 0.55 | 相邻元素最小起始间隔（24fps 下 13 帧） |
| `pause_duration` | 3.0 | 暂停卡时长 |
| `pause_text` | 请暂停，自己先算一遍 | 暂停卡底部提示条的主文案 |
| `module_gap` | 0.5 | 换模块时额外留白（秒） |
| `end_pad` | 0.4 | 片尾留白 |
| `first_title_at` | 0.35 | 首卡标题起始秒数，避免开场空页 |
| `modules` | — | `{"A": {"label","accent","tint"}}`，决定左侧色条与标签 |

## cards.json

顶层可以是数组，也可以是 `{"cards": [...]}`。

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一，同时是配音文件名 `audio/<id>.mp3` |
| `module` |  | 对应 `modules` 的键；缺省取第一个 |
| `layout` |  | `concept` / `list` / `steps` / `chips` / `stem` / `example`，默认 `concept` |
| `title` | ✅ | 卡片标题，自动成为第一个 `title` 节拍 |
| `ref` |  | 材料页码，如 `[1-1 p21–p23]` |
| `screen` |  | `main` 节拍内容为 null 时使用 |
| `tts` | ✅ | 旁白原文；触发词必须在此字符串中 |
| `diagram` |  | 图示名，见 `diagrams.md` |
| `diagramParams` |  | 图示参数 |
| `diagram2` |  | 触发词：图示数值层延后到这句话再出现 |
| `beats` | ✅ | `[kind, content, trigger]` 的数组 |
| `pause_after` |  | `true` 则本卡后插 3 秒暂停卡（保留本卡画面 + 遮罩 + 提示条） |
| `stem_bar` |  | 解析卡常驻题面（一行，含 LaTeX）；仅 `layout: steps` 用 |
| `ex_no` |  | 例题卡用：题号，如 `例 3.3`，显示在左栏徽章里 |
| `ex_title` |  | 例题卡用：左栏小题名（≤10 字） |
| `stem` |  | 例题卡用：完整题干，`\n` 分行；每行 ≤22 字，公式用 LaTeX |
| `used` |  | 例题卡用：本页用到的知识点，数组 2–3 条，每条 ≤22 字 |
| `gloss` | `true` | 设 `false` 关掉右上角速查小卡（符号总览卡、纯目录卡用） |

### 节拍类型

| kind | 用途 | 呈现 |
|---|---|---|
| `title` | 卡片标题 | 顶部逐字写出（缺省自动插在最前） |
| `main` | 一句话主张 | 46px 衬线；含 LaTeX 时走公式遮罩 |
| `note` | 要点 | 25px，带方块项目符 |
| `def` | **定义块**（知识锚点） | 23px，浅色整块，左上角「定义」标签；写法 `定义 1.2｜正文` |
| `sym` | **符号注**（只解释记号） | 19px 灰字，左侧「符号」小签；写法 `符号｜正文` |
| `kp` | **知识点块**（定义/定理/结论，与 `def` 同一套渲染） | 23px，浅色整块，默认标签「知识点」；写法 `定理 2｜正文`，竖线前可换成任意短标签 |
| `aside` | **高数备忘**（本卡用到的工具公式） | 右下角独立框，顶部 3px accent 边；写法 `公式｜一句人话`，一张卡最多一条 |
| `problem` | **题面行** | 25px，浅色整块卡片；相邻 `problem` 自动拼成一张卡（首尾圆角） |
| `step` | 解题步骤 | 自动编号 ①②③，25px |
| `banner` | 结论条 | 左边框 + 淡色底 |
| `formula` | 独立公式 | 32px，居中留白 |
| `chip` | 标签/选项 | 先虚线灰框，讲到时点亮（适合“五种分布”这类并列项） |
| `diagram` | 图示 | 右侧 410×392 区域，左→右擦除出现 |

### 题面卡（layout: stem）

例题题干卡要把**课本原题完整放上屏**，而不是只列条件。写法：

```json
["problem", "某设备有效期 \\(X\\) 的分布函数为", "某设备"],
["problem", "\\(F_X(x)=\\begin{cases}0, & x<0\\\\[2pt] 1-e^{-x/5}, & x\\ge 0\\end{cases}\\)", "x 小于零取 0"],
["problem", "求：(1) 均值 \\(E(X)\\)　(2) 方差 \\(D(X)\\)", "求两件事"]
```

- 连续 `problem` 会拼成一块浅色卡片，中间不留缝；组内多余空间全部落到卡片底部，不拆散。
- 题号写在 `title` 里（如 `例题 1.12｜指数分布：均值与方差`），屏幕上一眼能对回教材。

### 公式 / 符号速查小卡（glossary.json）

项目根目录放 `glossary.json`，每页右上角就会自动出现一张小卡，列出本页命中符号的一行解释：

```json
{"items": [
  {"k": "\\mathrm{Cov}(X,Y)", "sym": "\\mathrm{Cov}(X,Y)", "note": "协方差：同向偏离的程度"},
  {"k": "r_{XY}", "sym": "r_{XY}", "note": "相关系数：∈[−1,1]，只测线性"},
  {"k": "E(X\\mid Y", "sym": "E(X|Y)", "note": "条件期望：固定 Y 后 X 的均值"}
]}
```

- `k` 是定位串，必须能在该卡 beats 的 LaTeX 源码里**原样找到**；越具体越不会被别页抢走（用 `\\mu=E(X)` 而不是 `\\mu`）。
- `sym` 是显示写法（不含 `\\( \\)`），`note` 一句话、≤14 字。
- 每页按出现位置取前 2 条；全是已解释过的旧符号时只兜底 1 条；无命中则不出卡。
- 同一页避免语义重复的条目（`\\sigma^2` / `\\sigma`、`N(\\mu,\\sigma^2)` / `\\mu`），只留更具体的那个。

### 解析卡（layout: steps）的常驻题面

讲解例题时，题目不能消失。给解析卡加 `stem_bar`（一行紧凑题面，含 LaTeX 也行），
舞台会在标题下方固定一条「原题」栏，步骤区自动下移、可用高度从 448 缩到 366：

```json
{
  "id": "B5", "layout": "steps", "title": "例题解析｜先求密度，再用尾积分",
  "stem_bar": "\(F_X(x)=1-e^{-x/5}\ (x\ge0)\)，求 \(E(X)\) 与 \(D(X)\)",
  "beats": [["step", "...", "第一步求密度"]]
}
```

- 一行放不下就压缩写法：分段函数用 `g(x)=x-c (x<0)，x+c (x>=0)`，不搬完整 `cases`。
- 有 `stem_bar` 的卡，右侧图示会自动下移并等比缩小，不遮题面。
- 分段函数用 `\\begin{cases}` 内联写，不要用 `$$`；`display` 公式在卡里会撑破行高。
- 题面之后可留 1–2 条 `note` 当“解题钥匙”，但不许出现答案。

### 触发词写法

- 必须是 `tts` 中**连续出现**的片段（允许跨词，但不能跨标点被改写）。
- 越短越容易命中，但不要短到在句首重复出现（`t_at` 取第一次出现）。
- 想“开场就出”，用 `__start__`；`title` 缺省会用它，固定在 0.15s。
- 找不到时 `build_timeline.py` 会报 `missing` 并退出，按提示换词。

### 屏幕文字

- 一张卡最多一句主张 + 3–5 条要点；屏幕文字 ≤20 字（公式不计）。
- 公式一律 `\(...\)` 或 `$$...$$`，不要用 Unicode 上下标、不要贴图。
- 题干卡只放已知与所求；解法提示留给旁白或解析卡。

### 旁白

- 口语化，像聊天：先给结论，再解释，最后点一个易错点。
- 一张卡 150–300 字，约 30–55 秒；例题解析可到 60 秒。
- 讲到某个元素时再出现那个词——触发词就是“镜头切换点”。
- 例题：题干卡旁白只读题 + 提醒“先自己算”，解析卡逐步拆解并点坑。

## 一个最小示例

```json
{
  "id": "A1", "module": "A", "layout": "concept", "ref": "[1-1 p21]",
  "title": "随机变量不是“随机的数”，是映射",
  "screen": "\\(X:S\\to\\mathbb{R}\\) 单值映射",
  "tts": "先纠正一个直觉：随机变量不是一个飘来飘去的数，它是一个函数。",
  "diagram": "map",
  "beats": [
    ["title", null, "随机变量不是一个"],
    ["main", null, "它是一个函数"],
    ["note", "每个结果 \\(e\\) 贴一个实数标签", "贴了个标签"]
  ]
}
```
